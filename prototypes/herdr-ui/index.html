    How to drive it

    Click the terminal, then press g (stands for prefix g, bound to the plugin action). Keys for the open UI are on its bottom line. ←/→ switch variants. In the main area: o next pane, x close pane, 1–9 tabs.

    Scenario

    "+10 min" ages every FETCH_HEAD, so the fetch TTL kicks in on the next refresh.

    Mix and match

    Refresh triggers

    Each trigger runs one refresh: local status, a fetch for repos whose FETCH_HEAD is older than the TTL, then a report to Herdr. Herdr has no plugin timers; the only periodic thing is a tab_bar_right command entry in the user's config, which also prints a plain-text segment in the tab bar.
